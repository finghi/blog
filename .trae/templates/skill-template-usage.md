# Skill 模板使用指南

## 模板位置

模板文件位于：`.trae/templates/skill-template.md`

## 模板结构说明

### Front Matter（前置元数据）

```yaml
---
title: [技能名称]详细教程
icon: [图标名称]
# order: [排序数字]
date: [日期，格式：YYYY-MM-DD]
category:
  - 使用指南
tag:
  - [标签1]
  - [标签2]
  - [标签3]
---
```

**参数说明**：
- `title`：文章标题，建议使用 `[技能名称]详细教程` 格式
- `icon`：图标名称，参考 [FontAwesome](https://fontawesome.com/icons) 或项目中已使用的图标
- `order`：排序数字，数字越小越靠前
- `date`：文章发布日期，格式为 `YYYY-MM-DD`
- `category`：文章分类，通常为 `使用指南`
- `tag`：文章标签，3-5个相关标签

### 文章结构

#### 1. 简介（必填）

```markdown
<div style="font-weight:700; ">[技能简介：简要描述这个技能是什么，它的核心作用和价值]</div>
```

#### 2. 概述（必填）

- 什么是[技能名称]
- 为什么使用[技能名称]
- 应用场景

#### 3. 核心概念（必填）

- 基础概念
- 核心原理
- 可选：使用 tabs 展示不同角度的说明

#### 4. 快速开始（必填）

- 环境准备
- 基础使用
- 使用 tabs 展示安装和基础示例

#### 5. 进阶用法（可选）

- 高级特性
- 实战案例
- 使用 tabs 展示多个案例

#### 6. 最佳实践（必填）

- 性能优化
- 常见问题（使用 tabs 展示多个问题）
- 注意事项

#### 7. 与其他技术的对比（可选）

使用表格对比不同技术的特性

#### 8. 资源推荐（可选）

- 官方资源
- 学习资源
- 工具和插件

#### 9. 总结（必填）

总结文章的主要内容

#### 10. 附录（可选）

- API参考
- 常用命令
- 版本更新

## 使用方法

### 方法1：复制模板

1. 打开 `.trae/templates/skill-template.md`
2. 复制全部内容
3. 在 `src/posts/` 或 `src/docs/` 目录下创建新文件
4. 粘贴模板内容
5. 根据需要修改内容

### 方法2：基于现有文档

1. 找到类似的现有文档（如 `Promise详细使用教程.md`）
2. 复制其结构
3. 根据新技能的内容进行调整

## Tabs 语法说明

项目中使用的 tabs 语法：

```markdown
::: tabs#identifier
@tab 选项卡1名称

选项卡1的内容

@tab 选项卡2名称

选项卡2的内容

:::
```

**注意事项**：
- `#identifier` 必须唯一，建议使用有意义的英文标识
- 每个选项卡使用 `@tab 名称` 开始
- 选项卡内容可以是任何 Markdown 格式

## 文件命名规范

- 使用中文命名：`[技能名称]详细教程.md` 或 `[技能名称]详细文档.md`
- 示例：
  - `Promise详细使用教程.md`
  - `微前端详细教程.md`
  - `WebPack详细文档.md`

## 内容编写建议

### 1. 语言风格

- 使用简洁明了的中文
- 避免过于技术化的术语，必要时提供解释
- 使用列表、表格等格式提高可读性

### 2. 代码示例

- 提供完整可运行的代码示例
- 代码要有注释说明
- 重要部分使用高亮或说明

### 3. 结构层次

- 使用 `#`、`##`、`###` 等标题级别
- 保持逻辑清晰，层次分明
- 每个章节内容不宜过长

### 4. 图表使用

- 使用流程图说明复杂概念
- 使用表格对比不同方案
- 使用代码块展示示例

## 注意事项

1. **`<!-- more -->` 标签**：必须在简介之后添加，用于控制首页显示的内容长度
2. **Front Matter**：必须正确填写，否则文档可能无法正常显示
3. **代码块语言**：根据代码类型选择正确的语言标识
4. **链接格式**：使用相对路径链接项目内的其他文档
5. **图片路径**：图片应放在 `src/.vuepress/public/assets/images/` 目录下
